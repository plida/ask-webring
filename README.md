# ask-webring
Веб-кольцо для аск-сообществ.

# Деплой

[Страница репозитория](https://plida.github.io/ask-webring/index.html) (весь список асков)

# Как пользоваться?

Скопировать:
```
<div id="webring"></div>
<script src="https://plida.github.io/ask-webring/widget.js" defer></script> 
```
И вставить в html/php файл вашего сайта. Удобнее всего в футер (подвал).

Если сайт в списке репозитория - он включится в кольцо. Иначе запросите [администратора](https://vk.ru/id343114507) добавить вас в список.
